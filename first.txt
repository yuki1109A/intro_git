Gitの練習をしていきます。
基本的なワークフローを学びます。

cdコマンド
ディレクトリを移動します。

lsコマンド
ディレクトリの内容を表示します。
ls -a コマンドで、隠しファイルを含めたディレクトリ全内容を表示します。
ls -a .git/　gitの中身を確認

mkdirコマンド
ディレクトリを新規作成します。

rmコマンド
ファイルを削除します。

cpコマンド
ファイルをコピーします。

mvコマンド
ファイルの移動とファイル名の変更を行います。

ローカルリポジトリの新規作成
cd 対象フォルダ
git init





gitの基本的なワークフロー
①ファイルの変更をステージングエリアに追加する
git add ファイル名.拡張子

②ローカルリポジトリにコミットする
git commit
※メッセージ入力方法
半角英数→「i」→入力→「esc」→「:wq」→「enter」

③リモートリポジトリにプッシュする
git push -u origin main
